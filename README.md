# 🎯 Number Guessing Game 🎲

A cute, fun, and simple Python game where you try to guess the secret number hidden by the computer! 🤖🤖🤖

---

## 🎮 How to Play

1. The computer picks a secret number between **1 and 100** 🤫
2. Enter your guess 💭
3. The game tells you if the secret number is **Higher ⬆️** or **Lower ⬇️**
4. Guess it right to win! 🎉

---

# 🛠️ Tech Stack

* 🐍 **Python 3**
* 🎲 Built-in `random` module

---

## 🚀 Quick Start

1. Open your terminal or command prompt in the project directory.
2. Run the game:
   ```bash
   python main.py
